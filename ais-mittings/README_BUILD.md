# راهنمای بیلد و اجرا — شورای مشاوران هوش مصنوعی (AI Boardroom) — نسخه ۱.۱

## ۱) باز کردن پروژه در اندروید استودیو (ساده‌ترین راه)

1. اندروید استودیو **Narwhal (2025.1.1) یا جدیدتر** نصب کنید (JDK 17 همراه خودش هست).
2. `File > Open` و پوشه `Ais mittings` را انتخاب کنید.
3. Gradle Sync: اندروید استودیو نسخه Gradle 8.11.1 را که در `gradle/wrapper/gradle-wrapper.properties` تعیین شده، خودش دانلود می‌کند (نیازی به نصب دستی Gradle نیست).
4. اگر پیام نصب **SDK Platform 36 (Android 16)** آمد، تأیید کنید تا نصب شود.
5. دکمه **Run ▶** را بزنید — APK دیباگ با امضای پیش‌فرض ساخته و روی گوشی/شبیه‌گر نصب می‌شود (هیچ فایل keystore لازم نیست).

> نکته: اسکریپت‌های خط فرمان `gradlew` عمداً در بسته نیستند. اگر می‌خواهید از خط فرمان بیلد بگیرید، یک‌بار Gradle را نصب کنید و در ریشه پروژه اجرا کنید:
> `gradle wrapper --gradle-version 8.11.1` — از آن به بعد `./gradlew assembleDebug` کار می‌کند.

## ۲) تنظیم کلیدهای API (اختیاری اما توصیه‌شده)

- **راه داخل برنامه (بهترین راه):** روی هر پنجره مشاور آیکون ⚙ را بزنید و در هر جایگاه، «نام مدل»، «کلید API» و در صورت نیاز «اندپوینت» (مثلاً آدرس Ollama) را وارد کنید. کلیدها فقط روی خود گوشی و به‌صورت رمزنگاری‌شده (Android Keystore) ذخیره می‌شوند.
- **راه فایل .env (پیش‌فرض سراسری):** در ریشه پروژه فایل `.env` بسازید (کپی از `.env.example`) و کلیدهای عمومی را بگذارید:
  ```
  GEMINI_API_KEY=کلید شما
  OPENAI_API_KEY=کلید شما        # اختیاری
  ANTHROPIC_API_KEY=کلید شما     # اختیاری
  ```
  این کلیدها هنگام بیلد داخل `BuildConfig` قرار می‌گیرند؛ فایل `.env` در `.gitignore` است و کامیت نمی‌شود.
- **مدل‌های محلی / CLI:**
  - **Ollama:** در فیلد اندپوینت جایگاه، آدرس سرور را بدهید (مثلاً `http://192.168.1.50:11434`؛ روی شبیه‌ساز: `http://10.0.2.2:11434`) و نام مدل را مثل `ollama-llama3` بنویسید.
  - **سرورهای سازگار با OpenAI** (LM Studio، llama.cpp server، vLLM، LiteLLM و...): نام مدل را با `gpt` شروع کنید (یا هر نامی که با gpt شروع شود) و اندپوینت را مثل `http://192.168.1.50:1234/v1/` وارد کنید — کلید لازم نیست.
  - **روش node / MCP / Agent:** راهنمای کامل در داخل برنامه: آیکون تنظیمات (گوشه بالا-چپ) ← تب «📚 راهنمای جامع API و مدل‌ها».

## ۳) ساخت APK نهایی (Release)

1. یک keystore بسازید:
   ```
   keytool -genkey -v -keystore my-upload-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```
2. با متغیرهای محیطی بیلد بگیرید:
   ```
   KEYSTORE_PATH=/مسیر/my-upload-key.jks STORE_PASSWORD=*** KEY_PASSWORD=*** ./gradlew assembleRelease
   ```
   (اگر این متغیرها را ندهید، `assembleRelease` یک APK **امضانشده** می‌سازد که برای نصب مستقیم باید آن را امضا کنید.)
3. خروجی: `app/build/outputs/apk/debug/app-debug.apk` یا `.../release/app-release-unsigned.apk`

## ۵) عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| خطای `SDK location not found` | فایل `local.properties` را بسازید و `sdk.dir=/مسیر/Android/Sdk` را بنویسید (اندروید استودیو معمولاً خودش می‌سازد). |
| پیام دانلود SDK 36 | تأیید کنید؛ یا در SDK Manager پلتفرم 36 را نصب کنید. |
| پاسخ‌ها «⚠️ متن نمونه» هستند | کلید API معتبر در تنظیمات جایگاه یا فایل `.env` وارد کنید. |
| خطای Ollama در گوشی | آدرس `localhost` از گوشی به کامپیوتر نمی‌رسد؛ IP واقعی کامپیوتر را بدهید و در کامپیوتر `OLLAMA_HOST=0.0.0.0` بگذارید. |
| google-services.json نیست | مشکلی نیست؛ پلاگین فقط هشدار می‌دهد و بیلد ادامه می‌یابد. |
